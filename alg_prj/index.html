알고리즘 과제 풀이

5개 문제를 HTML/CSS/JS로 풀어가는 노트북 스타일 페이지 모음.

  • 01 최적 이진 탐색 트리 (OBST)
    동적 계획법으로 W·C·R 테이블을 채우고 최적 BST를 구성. 단계별 시각화 + D3 트리.
  • 02 브리지(Bridge) 찾기
    DFS 기반 disc/low 알고리즘. 텍스트로 그래프 입력 + 단계별 시각화 + 특정 간선 판별.
  • 03 탈출 문제 (Maximum Flow)
    격자 → 정점 분할 유량 네트워크, Edmonds-Karp. 격자 클릭 입력 + 증가 경로 단계별.
  • 04 무선 네트워크
    3D 정점 그래프의 연결 성분 분할. Three.js 3D 뷰 + r 슬라이더 + Union-Find 단계별.
  • 05 최소 비용 작업 배정 (MCMF)
    SPFA 기반 MCMF. 비용 행렬 편집 + 이분 그래프 + 역방향 음수 잔여 시각화.
