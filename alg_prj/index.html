알고리즘 팀 프로젝트

5개 문제를 HTML/CSS/JS로 풀어가는 노트북 스타일 페이지 모음. 각 페이지는 알고리즘을 처음 보는 사람도 따라올 수 있게 차근차근 설명한다.

  • 01 최적 이진 탐색 트리 (OBST)
    동적 계획법으로 W·C·R 테이블을 채우고 최적 BST를 구성. 단계별 시각화 + D3 트리.
  • 02 브리지(Bridge) 찾기
    DFS 기반 disc/low 알고리즘. 텍스트로 그래프 입력 + 단계별 시각화 + 특정 간선 판별.
  • 03 탈출 문제 (Maximum Flow)
    그리드 → 유량 네트워크 변환, Edmonds-Karp/Dinic. (작성 예정)
  • 04 무선 네트워크
    3D 정점 그래프의 연결 성분 분할. Three.js 3D 뷰 + r 슬라이더 + Union-Find 단계별.
  • 05 최소 비용 작업 배정 (MCMF)
    이분 그래프 최대 매칭 + 최소 비용 최대 유량. (작성 예정)
