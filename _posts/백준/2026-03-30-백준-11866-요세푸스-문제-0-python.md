[문제 링크](https://www.acmicpc.net/problem/11866)

## 코드 설계

- **K번째 사람을 제거한다** 는 표현이 무엇을 뜻하는 것인지 아는 게 중요했다.
- 원탁 내에 있는 3번째 사람 (리스트로 따지면 `리스트[2]`) 만 제거하라는 게 아니라, 가장 최근에 제거한 사람이 앉아있던 위치를 첫 번째로 잡고 시계방향으로 세 번째에 있는 사람을 제거하는 과정을 반복하라는 것이다.

그림이 이해가 더 편할 지 모르겠지만 그림으로도 대충 그려보았다.

## 코드 작성

```Python
import sys;
input = sys.stdin.readline

eliminated = [] # 제거된 사람 번호 리스트
n, k = map(int, input().split())
seq = [i for i in range(1, n+1)]
cursor = 0
 
while (len(seq) > 0):
    cursor += (k - 1) # k번째 사람을 제거하라는 것이지, k번 뒤에 있는 사람을 제거하라는 것이 아니기 떄문.
    if (cursor >= len(seq)): # 인덱스를 넘어가버리면
        cursor %= len(seq) # 나머지 연산으로 맨 앞으로 돌아오게 하기
        # cursor = 3인데 len(seq)가 4인 경우, cursor = 3 % 4로 cursor = 1이 나오게 해야 하는 것.
    eliminated.append(str(seq.pop(cursor)))
    # str로 안하면 28번째 줄 join에서 에러난다.

print("<", end="")
print(", ".join(eliminated), end="")
print(">")

```
