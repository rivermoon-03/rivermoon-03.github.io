## 문제 해석
처음 이 문제를 보았을 때, 잠시 이해하기 어려웠지만 입력부, 출력부를 돌려보다 보니 이해가 되었다.
 - 티셔츠는 부족하지만 않다면 여유분을 둘 수 있지만, 펜은 여유분을 두지 않음에 주의. 

```
23 -> 인원 수
3 1 4 1 5 9 -> 사이즈별 신청자 수
5 7 -> T, P
```


```
7 -> 티셔츠를 T(5)장씩 "최소 몇 묶음" 주문해야 하는지에 대한 답
3 2 -> 펜을 P(7)자루씩 "최대 몇 묶음" 주문할 수 있는지 / 낱개로는 몇 자루 주문해야 하는지 구하기
```

문제에서 *그 때 펜을 한 자루씩 몇 개 주문하는지 구하세요.* -> 이 부분 때문에 이해가 힘들었다. "낱개로는 몇 개 주문하는지 구하세요" 라고 적혀있었으면 바로 이해할 수 있었을 것 같은데..


출력부 첫 줄에서 티셔츠 7묶음이 나오는 이유는 아래와 같다.
 - T = 5이다. 즉 티셔츠는 5벌에 한 묶음으로 판매한다.
 - 사이즈별 신청자 수를 보면, 3벌, 1벌, 4벌, 1벌, 5벌 (각각 1묶음 선에서 가능), 9벌 (2묶음 필요함). 즉 1 + 1 + 1 + 1 + 1 + 2 = 7묶음.

출력부 두 번째 줄에서 5묶음과 낱개 7개가 나오는 이유는 아래와 같다.
 - 인원은 23명, 펜은 P(7)개에 한 묶음이니, 3묶음 + 낱개 2개가 필요하다.

---



```python
# 입력
joiner = int(input())
size = list(map(int, input().split()))
t, p = map(int, input().split())

# 처리
t_couple = 0; 
pen_couple = 0;
pen_single = 0;

for s in size: # 티셔츠 몇 묶음씩 주문해야 하는지 계산
  t_couple += s // t
  if (s % t != 0): t_couple += 1 # 필요한 건 6벌인데 5벌에 한 묶음으로 파는 경우, 2묶음이 필요하기 때문.

pen_couple = joiner // p
pen_single = joiner % p

# 출력

print(t_couple)
print(pen_couple, pen_single)
```
