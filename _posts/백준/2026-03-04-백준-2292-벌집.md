## 문제 인식
가장 안쪽의 육각형을 1단, 그 밖을 2단.. 으로 생각했을 때,
1단을 감싸기 위해서는 6개, 2단을 감싸기 위해서는 12개, 3단을 감싸기 위해서는 18개..

6의 배수만큼 증가하는 계차수열로 볼 수 있다.


## 코드 작성
입력으로 벌집 번호를 받았을 때, 방을 최소 몇 개 거치는지를 출력으로 내 주어야 한다.
일단 기본적으로 1번 방에서 시작하므로, 무조건 방은 1개 이상을 거친다.

```rooms = 1``` 로 두고 시작한다.
사용자에게 입력받은 벌집의 번호를 n번이라고 가정할 때, 

1 + (1 * 6)번 > n번 > 1번이라면, 방을 2개만 거치면 될 것이다.<br>
1 + (2 * 6)번 > n번 > 7번이라면, 방을 3개 거치게 될 것이다.

```python
n = int(input())
rooms = 1
number = 1

while True:
    if number >= n: break
    number += (6 * rooms)
    rooms += 1

print(rooms)
```
