## 문제 인식
달팽이는 v미터의 막대를 올라야 한다.<br>
a미터를 아침에 오르고, b미터를 밤에 미끄러져 내려간다.

단, 아침에 v미터의 막대를 오르는 데에 성공했다면, 밤을 보내지 않고 성공 처리를 해야 한다.

### 상황 예시
- 6m 막대, 아침에 3m 상승, 밤에 1m 하강.
    - 1일차에는 0+3-1=2m
    - 2일차에는 2+3-1=4m
    - 3일차에는 4+3=7m (종료)


### 1차 시도 (실패)
```python
a, b, v = map(int, input().split())

# v미터 막대. a미터 올라가고 b미터 미끄러짐.
# 10미터를 4미터 올라가고 2미터 미끄러진다면

day = 0
metre = 0

while True:
    metre += a
    day += 1
    if metre >= v: break
    metre -= b

print(day)
```

달팽이가 올라가고 미끄러지는 과정을 그대로 코드로 작성했었다.<br>
잘 작동하는 것처럼 보였지만, `0.25초`라는 시간 제한에 걸려 시간 초과로 채점에 실패하였다.

### 머리 더 쓰기

그래서, 시간 제한을 풀어내기 위해 여러가지 생각을 거쳤다.<br>상황 예시를 보면,

- 6m 막대, 아침에 3m 상승, 밤에 1m 하강.
    - 1일차에는 0+3-1=2m
    - 2일차에는 2+3-1=4m
    - 3일차에는 4+3=7m (종료)


과 같은 과정을 거쳐 달팽이가 올라오는 데에 성공하였었는데,

n일차에 등반을 완료한다고 가정하면, n-1일차에는 무조건 오른 높이가 (v-a)m보다 같거나 높아야 한다는 것을 알 수 있었다.

(3일차에 7m 막대 등반을 완료하려면, 2일차에는 7-3=4m까지는 올라와야, 다음 날 등반함을 완료하게 된다는 것이다.)

1일차부터 n-1일차까지는 낮과 밤을 모두 거치므로, a미터 올라가고 b미터 내려가는 것을 모두 거친다. 즉 하루에 (a-b)미터를 오르는 것이다.

즉,


  - (v-a) / (a-b)를 하면, n-1이 무엇인지 알 수 있다.
  - 만약 (v-a) / (a-b)가 소수로 끝나는 경우, 올림한다. (3.1일 같은 경우에도, 달팽이는 다음 날 아침에 오르기 때문에 하루가 더해져야 한다.)
 
### 코드 작성
이를 코드로 나타내면 아래와 같이 나올 수 있다.
```python
a, b, v = map(int, input().split())



# 6m 막대, 3m 상승, 1m 하강.
# d1 : 0 + 3 - 1 = 2
# d2: 2 + 3 - 1 = 4
# d3: 4 + 2 (end)

# n일차에 (v-a)m 이상까지 올라왔다면, 다음 날에 무조건 올라온다.
# 하루에 올라가는 거리는, (a-b)m이다.

day = (v-a) // (a-b)
if (v-a) % (a-b) != 0: day+=1
print(day+1)
```
