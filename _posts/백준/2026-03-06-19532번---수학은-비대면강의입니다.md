### 코드
```python
# 19532번
# ax + by = c, dx + ey = f를 구해야 하는 문제이다.
# -> 브루트 포스보다 더 나은 방법들이 있을 것 같긴 하다.
# 하지만 일단 브루트 포스로 풀어보도록 하자.

a, b, c, d, e, f = map(int, input().split())

found = False
for x in range(-999, 1000):
    for y in range(-999, 1000):
        if a*x + b*y == c and d*x + e*y == f:
            found = True
            break
    if found:
        break
print(x, y)
```

### 설명과 풀이 과정
이 문제도 브루트 포스 문제라, 무식하게 -999~999 (문제 조건) 까지 모두 넣어보는 방법으로 때려 맞추면 되는 문제였다.

브루트 포스를 쓰지 않겠다면, 가감법을 써서 구하는 방법도 있을 것이다.
