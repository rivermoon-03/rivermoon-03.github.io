# 03. 유스케이스 재료

> STEP 4(다이어그램)와 STEP 5~8(명세서)에서 공통으로 참조하는 **재료 모음**. 액터 정의·유스케이스 목록·그룹·관계·매핑을 표로 정리한다.

---

## 1. 액터 정의

| 약칭 | 액터 | 유형 | 설명 | 주요 권한 |
|---|---|---|---|---|
| **STU** | 학생 / 연구원 | 사람 (1차 액터) | 시스템 주 사용자. 소속 팀 Quota 내에서 서버를 요청·사용·반납한다. | 본인 예약 조회·생성·취소·반납, 초과 시 승인 요청, 알림 수신 |
| **MGR** | 팀 관리자 / 교수 | 사람 (1차 액터) | 팀 단위 운영을 책임진다. 팀원의 초과 요청을 결재하고 Quota를 세분화한다. | 팀 Quota·사용 현황 조회, 초과 요청 승인/거절, 팀원별 Quota 설정 |
| **ADM** | 서버 관리자 | 사람 (1차 액터) | 시스템 최고 권한자. 서버 자원과 전체 정책을 운영한다. | 서버 등록/삭제, 점검 스케줄, 전체 Quota·유휴 정책 설정, 전체 현황 조회 |
| **SYS** | 모니터링 시스템 «system» | 시스템 (2차 액터) | 사람 개입 없이 동작하는 자동 액터. 스케줄·이벤트 기반으로 실행된다. | 사용률 수집, 유휴 감지/자동 회수, 만료 자동 반납, 승인 타임아웃 자동 거절, 알림 발송 |

## 3. include / extend / generalization 관계

### 3.1 include (항상 포함)

| 기준 UC | 포함 UC | 의미 |
|---|---|---|
| UC04 (서버 예약 요청) | *Quota 확인* | 예약 시 항상 Quota 확인 (UC로 별도화하지 않고 주흐름에 내장) |
| UC05 (즉시 서버 요청) | *Quota 확인* | 동일 |
| UC08 (Quota 초과 요청) | UC09 (초과 요청 승인/거절) | 초과 요청은 반드시 결재 흐름으로 이어짐 |
| UC09 (초과 요청 승인/거절) | UC03-a (승인/거절 알림 수신) | 결재 결과는 반드시 통지 |
| UC15 (유휴 감지 및 자동 회수) | UC03-b (유휴 회수 경고 알림 수신) | 회수 전 반드시 경고 |
| UC16 (예약 만료 자동 반납) | UC03-c (예약 만료 알림 수신) | 만료 시 반드시 통지 |
| UC17 (승인 타임아웃 자동 거절) | UC03-a (승인/거절 알림 수신) | 자동 거절도 통지 대상 |

### 3.2 extend (조건부 확장)

| 기준 UC | 확장 UC | 조건 |
|---|---|---|
| UC04 (서버 예약 요청) | UC08 (Quota 초과 요청) | 요청 시점에 Quota 초과 |
| UC05 (즉시 서버 요청) | UC08 (Quota 초과 요청) | 동일 |
| UC04 (서버 예약 요청) | UC03-d (예약 충돌 알림 수신) | 동시 요청으로 낙관적 잠금 충돌 발생 |
| UC07 (서버 반납) | *다음 대기자 알림 발송* | 대기자 존재 시 (주흐름에 내장) |

### 3.3 generalization (일반화)

| 부모 UC | 자식 UC |
|---|---|
| UC03 (알림 수신) | UC03-a, UC03-b, UC03-c, UC03-d |

> 다이어그램에는 UC03을 상단에 두고 4개 자식을 점선 화살표(open arrow)로 연결한다.
